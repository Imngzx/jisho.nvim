1. Introduction                                         *jisho-introduction*

jisho.nvim looks up Japanese words on Jisho.org without blocking the editor
and shows the results as Markdown in a floating window.

Requires Neovim 0.13+ (|vim.async|, |vim.net.request|). `curl` is used when
|vim.net.request| is unavailable.

Optional:
- snacks.nvim       window and history picker
- budoux.lua        Japanese word segmentation for `w` / `b`
- render-markdown.nvim  nicer Markdown rendering

==============================================================================
2. Installation                                         *jisho-installation*

>lua
    vim.pack.add({ 'https://github.com/Imngzx/jisho.nvim' })
    require('jisho').setup()
<
See the README for lazy.nvim and resonance.nvim specs.

==============================================================================
3. Setup                                                       *jisho-setup*

`setup()` is optional; these are the defaults:
>lua
    require('jisho').setup({
      use_snacks = pcall(require, 'snacks'),  -- false: native float
      use_budoux = pcall(require, 'budoux'),  -- Budoux `w` / `b`
      layout = 'spacious',  -- 'compact' | 'spacious' | 'super_spacious'
      window = {
        width = 0.6,         -- ratio of the editor width
        height = 0.7,        -- ratio of the editor height
        border = 'rounded',  -- any 'winborder' value
      },
    })
<
`setup()` also loads the disk cache and history.

==============================================================================
4. Usage                                                       *jisho-usage*

Commands:                                                  *:Jisho*
    :Jisho [word]           Look up {word}, or the word under the cursor.
                                                           *:JishoHistory*
    :JishoHistory           Open the search history.
                                                           *:JishoRefresh*
    :JishoRefresh [word]    Look up again, bypassing the cache.
                                                           *:JishoDedupe*
    :JishoDedupe {subcmd}
          inflight          List requests still in flight.
          clear-inflight    Forget in-flight requests.
          clear-cache       Clear the result cache.
          refresh [word]    Same as |:JishoRefresh|.

Lua API:                                                       *jisho-api*
>lua
    require('jisho').search(word)  -- nil/'' = word under the cursor
    require('jisho').history()
<
Example keymaps:
>lua
    vim.keymap.set('n', '<leader>tj', function()
      require('jisho').search()
    end, { desc = 'Jisho (word under cursor)' })

    vim.keymap.set('x', '<leader>tj', function()
      local text = vim.fn.getregion(vim.fn.getpos('v'), vim.fn.getpos('.'),
        { type = vim.fn.mode() })
      vim.api.nvim_feedkeys(vim.keycode('<Esc>'), 'n', false)
      require('jisho').search(table.concat(text, ' '))
    end, { desc = 'Jisho (selection)' })
<
==============================================================================
5. Result Window                                       *jisho-result-window*

Up to 5 results. Each shows the word with its reading, common and JLPT
tags, other forms, tags, and numbered senses (parts of speech, definitions,
usage notes, see also, sense tags).

    j / k          Next / previous entry or sense
    w / b          Budoux word jumps (needs budoux.lua and `use_budoux`)
    q / <Esc>      Close

==============================================================================
6. History                                                   *jisho-history*

|:JishoHistory| lists past searches, newest first, with timestamps (max 100).
<CR> searches the entry again. Uses snacks.picker when `use_snacks` is set,
otherwise a floating window (q / <Esc> to close).

==============================================================================
7. Cache and Deduplication                                     *jisho-cache*

Results are cached for 5 minutes, keyed by the trimmed search text, and
saved with the history to `stdpath('cache')/jisho_cache.json`, so they
survive a restart while still fresh.

Searching a word that is already being fetched does not send a second
request: every caller gets the same result.

==============================================================================
8. Layouts                                                   *jisho-layouts*

    compact         No blank lines between blocks
    spacious        One blank line (default)
    super_spacious  Two blank lines

An unknown name falls back to `spacious`.

==============================================================================
9. Events                                                     *jisho-events*

                                                           *JishoWindowOpened*
`User JishoWindowOpened` fires after a result window opens, with
`data = { buf = bufnr, win = winid }`:
>lua
    vim.api.nvim_create_autocmd('User', {
      pattern = 'JishoWindowOpened',
      callback = function(ev) vim.wo[ev.data.win].linebreak = true end,
    })
<
==============================================================================
10. Troubleshooting                                  *jisho-troubleshooting*

Nothing happens       Check |:messages|, your connection, and that `curl`
                      is in PATH if |vim.net.request| is missing.
`w` / `b` are plain   budoux.lua not installed, `use_budoux = false`, or
                      the line has no Japanese text.
Stale result          |:JishoRefresh| {word}.
